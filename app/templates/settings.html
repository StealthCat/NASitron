HTTPS API
Defaults to Mailjet Send API v3.1. You can point this at another HTTPS relay that implements the same request format.

Mailjet-compatible delivery uses HTTPS Basic Authentication with the API key as the username and secret key as the password. Each configured recipient is sent as a separate message object.

SMTP passwords and Mailjet credentials are encrypted at rest using key material derived from NASITRON_SECRET_KEY.
