2. Trust this NASitron instance's internal CA

Required for curl

This instance uses Caddy's internal CA. Export its root certificate from the NASitron Docker host and transfer that certificate to the remote NAS through a trusted channel. Do not use curl -k when piping a script to root.

docker compose cp caddy:/data/caddy/pki/authorities/local/root.crt ./nasitron-caddy-root.crt
scp ./nasitron-caddy-root.crt root@REMOTE_NAS:/tmp/nasitron-caddy-root.crt
