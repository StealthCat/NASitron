Encrypted backup and restore

Stop the application and run the backup utility in its configured environment. It captures the SQLite database, data-directory configuration and NASITRON_SECRET_KEY in a password-encrypted archive. Restore into a new empty directory; existing installations are never overwritten.

python -m app.backup create /backup/nasitron.nsb
python -m app.backup restore /backup/nasitron.nsb /restore/nasitron

Keep the backup password separately. Deployment environment settings and Caddy's separate data volume must also be backed up. See README for Docker commands and recovery steps.
